# Сундук приключений

Браузерная версия настольной игры для 1–6 игроков на одном устройстве.

## Возможности

- автоматическое применение базовых правил;
- выбор количества игроков и приключений;
- объёмные анимированные кубики;
- жетоны сокровищ и счётчик опыта;
- локальное автосохранение партии в браузере.

## Запуск локально

Откройте папку проекта через любой статический HTTP-сервер, например:

```bash
python -m http.server 8000 --directory dist
```

После этого откройте `http://localhost:8000`.

## GitHub Pages

Публикация содержимого `dist` выполняется автоматически при обновлении ветки `main`.
